# Physical Hardware Prototyping & Caliper Logging Skill

Enforces rigorous physical measurement, coupon testing, and tolerance verification before committing full-scale manufacturing runs.

## Tolerance Ladder Guidelines

- **Press-Fit (Interference):** 0.05mm - 0.10mm clearance
- **Snug Slide-Fit:** 0.15mm - 0.20mm clearance
- **Loose Free-Spinning Fit:** 0.30mm - 0.40mm clearance

## Workflow

1. Model test coupons for critical mating interfaces.
2. Fabricate/print initial coupons.
3. Measure with digital calipers and log variance.
4. Update parametric model tolerances based on physical ground truth.
