# Backdrop Visual & Figure Style Guide

## 1. Framing & Background
- **Aspect & Canvas:** Standard horizontal layout (16:9 landscape) or vertical (9:16 portrait), clean borders, centered in document.
- **Padding:** 12–16 pt outer margin on technical drawings.
- **Border:** Thin 0.5–1 pt boundary box on vector diagrams.

## 2. Color System & Fastener Coding
- **Red Fastener Icons (`#D32F2F`):** Standard wood/face screws (corners x2, B-to-D ends, C-to-A laminations).
- **Blue Fastener Icons (`#0288D1`):** Structural framing screws driven through outer A rails into end grain of cross joists D.
- **Lumber Outline:** Light gray/wood tone with clear component letters (A, B, C, D) in bold sans-serif circular callouts.

## 3. Privacy & Human Subject Blurring
- **Face Privacy:** All human faces (students, volunteers, crew members) present in fabrication, assembly, and field photos must have a strong Gaussian blur filter applied prior to approval and document embedding.
- **Source Privacy:** Raw, unblurred source photos in `assets/incoming/` are strictly ignored from version control (`.gitignore`) and never committed to public repositories.

## 4. Typography & Alt Text
- **Labels:** Arial / Helvetica sans-serif bold 10–12 pt.
- **Alt Text:** Complete description of geometry, dimensions, joist spacing, component positions, and screw patterns for accessibility.
